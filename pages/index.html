About

oc-html is a minimalistic and lightweight HTML viewer and browser for OpenComputers, a Minecraft mod. It runs on the Lua 5.3 architecture and lets you view local HTML files and browse the web from inside the game.

Features

  • Web browsing
  • Page navigation
  • Smart page caches
  • SSL support
  • Image viewing

In a little more detail:

  • The smart cache lets you go back to a previous page without fetching the entire file again.
  • Link navigation support.
  • Browser tab support.
  • Image viewing (for now PNGs; other extensions will be supported in a future version).

Requirements

The script is tested against a machine with 4MB of storage and 2MB of memory. The script itself takes up about 200kb of space.

ComponentNeeded for
Internet cardViewing online websites
Graphics cardViewing images
2M disk spaceThe smart page cache saves viewed sites to disk temporarily, and benefits from having more free space.
1M memoryLoading large websites may take especially much; keep this in mind!

Install and usage

Check the releases page and navigate to the latest version. Pull html-install.lua onto your OpenComputers instance and run it.

To install to the root directory of the machine:

html-install --prefix /

Then view a local file or a web page:

html ./index.html
html https://example.com/

Run html --help for more information.
