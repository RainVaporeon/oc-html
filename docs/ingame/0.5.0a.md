# In-game check: release 0.5.0a

Goal: check Tab wrap, Up and Down on links, keys during a load, abort and
the disk cache in game. Run the steps in order. Mark each item pass or fail,
and paste back the exact text of every failure.

Note: the repository is not pushed yet. Copy the files by hand as for 0.4.0a
(the release folder `releases/0.5.0a/`, or `html-install.lua` from it, goes
into the game by the way you used for 0.4.0a). Then `<BASE>` below means that
copy.

Needs: an Internet Card, a server that allows web requests, a keyboard with
NumPad, and a stopwatch (or a clock) for the reaction times.

## 1. Install and upgrade

```
wget -f <BASE>/releases/0.5.0a/html-install.lua /home/html-install.lua
/home/html-install.lua
ls /home/lib/html
```

- 1.1 New install: it prints `html-install: oc-html 0.5.0a`, one
  `<path> <size> bytes` line per file, and `installed 11 files`.
- 1.2 Upgrade over 0.4.0a: the same lines. `ls /home/lib/html` shows
  `cache.lua` with the other 10 modules. No `.old` or `.new` file stays in
  `/home/bin` or `/home/lib/html`. It never prints `; old files kept`.

## 2. Links: Tab and Up/Down

Make `/home/c.html`. The first paragraph has three links on one line.

```
<title>C</title><h1>Links</h1>
<p><a href="a.html">one</a> <a href="b.html">two</a> <a href="c.html">three</a></p>
<p><a href="a.html">four</a></p>
<p>text</p>
```

Run `html /home/c.html`.

- 2.1 Tab four times. Expected: the selection goes one, two, three, four,
  then back to one (wrap). Shift+Tab on one: it goes to four.
- 2.2 With nothing selected press Down. Expected: one is selected. Down:
  two (same line, to the right). Down: three. Down: four (next line). Down
  again: nothing happens (no wrap, no scroll on a short page).
- 2.3 Up from four: three. Up: two. Up: one. Up again: nothing.
- 2.4 Open `html https://en.wikipedia.org/wiki/OpenComputers`. Press Down
  repeatedly. Expected: the selection moves link by link, also along a line
  with several links. When no link is left on the screen, the page scrolls
  one page and the first link in the new rows is selected. Up does the same
  backwards.
- 2.5 Make `/home/n.html` with only `<title>N</title><p>text</p>` repeated
  100 times and no link. `html /home/n.html`, Down, Up: Down scrolls one
  page, Up scrolls one page back.

## 3. Keys during a load (slow load)

Use a slow page: a large Wikipedia article, or `<BASE>/tests/pages/large.html`
served by a server, or any host that is slow to answer. Start each test with
a page on screen and follow a link or press `g` and enter the slow URL. Use
the stopwatch. Write down how long the program takes to react after each key
(for example `z: 0.3 s`).

- 3.1 `z` during the load: it aborts at once and goes back.
  Reaction time: ____
- 3.2 Backspace during the load: it aborts and goes back at once.
  Reaction time: ____
- 3.3 Left during the load: the same. Reaction time: ____
- 3.4 Right during the load: nothing happens, the load goes on.
- 3.5 `q` during the load, then `n`: the load goes on. Do it again, then
  `y`: the program quits.
- 3.6 Press several keys quickly during a load (for example Down, Down, z).
  Expected: no key is lost, the abort works.

## 4. Abort and the page area

- 4.1 Abort while connecting: `g`, `http://example.com:81/`. While the status
  shows `Connecting`, press `z`. Expected: the previous page stays as it was.
- 4.2 Abort after rendering started: follow a link to a big page. When the
  page area is cleared and the first lines show, press `z`. Expected: the
  previous page shows again at once, with no network wait (it comes from the
  cache). Write down how long it takes: ____
- 4.3 Press Backspace and Right. Expected: the aborted page has no history
  entry.

## 5. Disk cache

Run `df /home` or `df` and write down the free space: before ____.

- 5.1 Open a large page, for example a wiki page of a few hundred KB:
  `html https://en.wikipedia.org/wiki/OpenComputers` (or a longer article).
  Follow a link. Press Backspace. Expected: the first page appears at once,
  without the long download. Write down how long it took: ____
- 5.2 While html runs the cache folder is `/home/.cache/html`. You cannot
  list it while html runs (no second screen, and Ctrl+Alt+C stops html).
  Instead: after step 5.1 quit html, then run `ls /home/.cache/html`.
  Expected: the folder is empty (or has no page files) after quitting.
  Optional: if you have a second computer or screen on the same disk, run
  `ls -l /home/.cache/html` there right after the Backspace of 5.1, and
  write down the file names and sizes.
- 5.3 Run `df` again and write down the free space: after ____. Expected: it
  equals the number before (the cache is empty).
- 5.4 Press `r` on a page. Expected: it fetches again (the loading phases
  show; the cache is not used for a reload).
- 5.5 Forward (Right) after Back also shows without a download.
- 5.6 Limits (read, no action): the cache keeps at most min(25% of free
  disk, 2 MiB) in total, 16 pages, and leaves 64 KB of the disk free. Open
  more than 16 pages and press Back on the oldest: it may download again.
  Write down what you see.

## 6. Status hint

  (`html --help` is not needed). Press `?`: the list says `Up, Down: move
  between links`.
