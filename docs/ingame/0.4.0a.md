# In-game check: release 0.4.0a

Goal: check link following, history, reload, the go prompt, abort and the
error popups in game. Run the steps in order. Mark each item pass or fail,
and paste back the exact text of every failure.

`<BASE>` is the raw URL of the repository source. Use the version path
`releases/0.4.0a/`, not `releases/latest`.

Needs: an Internet Card, a server that allows web requests, and a keyboard
with NumPad. Step 1 and the local steps need no card.

## 1. Install

```
wget -f <BASE>/releases/0.4.0a/html-install.lua /home/html-install.lua
/home/html-install.lua
```

- 1.1 New install: it prints `html-install: oc-html 0.4.0a`, one
  `<path> <size> bytes` line per file, and `installed 10 files`. The files
  include `/home/lib/html/history.lua` and `/home/lib/html/url.lua`.
  `html --help` lists the keys (Tab, Left or Bksp, Right, g, r, z, ?).
- 1.2 Upgrade over 0.3.0a: the same lines. `ls /home/lib/html` shows
  `history.lua` and `url.lua`. No `.old` or `.new` file stays in
  `/home/bin` or `/home/lib/html`. It never prints `; old files kept`.

## 2. Key codes

Open any page with links: `html /home/a.html` (make it in step 7) or
`html http://example.com`. Press each key once and write down what it does.
Expected values are in brackets.

- 2.1 Tab [selects the next link, reverse video, its URL on the status line].
- 2.2 Shift+Tab [selects the previous link]. Note whether `isShiftDown`
  works: pass if it goes backwards, fail if it goes forward like Tab.
- 2.3 Backspace [back]. 2.4 Left [back]. 2.5 Right [forward].
- 2.6 NumPad 4 and NumPad 6 with NumLock off [Left and Right: back and
  forward]. 2.7 The same with NumLock on [no action, they are digits].
- 2.8 `r` [reload]. 2.9 `g` [the `Go to:` prompt]. 2.10 `?` [key list popup].
- 2.11 `z` during a load [abort]. Press `z` with no load [nothing].
- Write the result of each as `key: action` (for example
  `NumPad 4, NumLock off: back`). Press Enter or a key to close the popup.

## 3. A real site with many links

Run `html https://en.wikipedia.org/wiki/OpenComputers` (or the GTNH wiki).

- 3.1 Tab through at least 20 links. The selected link is in reverse video,
  the page scrolls to keep it visible, and the status line shows its URL.
- 3.2 Select a link and press Enter. The new page loads (phases show on the
  status line). The status line shows the new title.
- 3.3 Back (Backspace). The first page shows at the same scroll position and
  with the same link selected.
- 3.4 Forward (Right). The second page shows again.
- 3.5 Press `r`. The page loads again (one more request).
- 3.6 Follow an `#anchor` link (for example a table of contents entry). The
  page jumps to the section at once, with no loading phases and no request.
- 3.7 `html "https://en.wikipedia.org/wiki/OpenComputers#Features"`: the page
  opens at that section.

## 4. Memory after navigation

- 4.1 Run `free` and write down the free memory. Start
  `html https://en.wikipedia.org/wiki/OpenComputers` and quit when it shows.
  Run `free` again and write it down.
- 4.2 Follow a link, press Backspace, and repeat 10 times. Then quit.
  Run `free`.
- 4.3 Pass if free memory after step 4.2 is not much lower than after
  step 4.1 and does not fall on each round. Write down: the number before,
  the number after 3 rounds, after 10 rounds. If the program stops with a
  memory message, paste it.

## 5. The go prompt

- 5.1 `g`, type `https://example.com/`, Enter. The page loads. Backspace
  returns to the previous page.
- 5.2 Make a folder and a file with a space: `mkdir "/home/my dir"` and
  `cp /home/a.html "/home/my dir/a b.html"`. In the viewer press `g`, type
  `/home/my dir/a b.html`, Enter. The page shows (the space is typed).
- 5.3 `g`, type `http://`, Enter. A popup shows `html: invalid URL: http://`
  and the page stays. Esc in the prompt cancels it.

## 6. Abort (z)

- 6.1 In phase 1: follow a link to a host that does not answer, for example
  `g` then `http://example.com:81/`. While the status shows `Connecting`,
  press `z`. The old page stays and nothing changes.
- 6.2 During the render: follow a link to a big page (for example
  `<BASE>/tests/pages/large.html` or a long Wikipedia article) and press `z`
  while the byte count or the render runs. Expected: the previous page loads
  again. Then press Backspace and Right: the aborted page has no history
  entry.
- 6.3 `z` during a reload (`r`) of a big page, after the render began.
  Expected: the status line shows `[aborted] <url>` with an empty page, and
  `r` loads it again. Do the same for Backspace and Right.

## 7. Local pages

Make `/home/a.html`:

```
<title>A</title><h1>Page A</h1><p><a href="b.html">to B</a> <a href="#end">to the end</a></p>
<p>text</p><p id="end">The end</p>
```

and `/home/b.html`:

```
<title>B</title><h1>Page B</h1><p><a href="a.html">to A</a></p>
```

- 7.1 `html /home/a.html`, Tab, Enter: page B shows. Tab, Enter: page A shows.
  Backspace: back to B. Backspace: back to A. Right: forward to B.
- 7.2 The `#end` link jumps without a reload.
- 7.3 `html /home/a.html#end` opens at the section.
- 7.4 Open a text file: `html /home/b.html.txt` after `cp /home/b.html
  /home/b.html.txt`, and a Lua file: `html /usr/bin/ls.lua` (or any `.lua`).
  Both show as text, not as HTML.
- 7.5 Add a link to a missing file to `a.html`
  (`<a href="none.html">x</a>`) and follow it. A popup shows
  `html: file not found: /home/none.html` and the page stays.

## 8. Errors

- 8.1 Follow or type a link that gives a 404 (for example
  `g`, `https://en.wikipedia.org/wiki/Zzzzqqq_no_such_page_9`). A popup shows
  two lines: `[HTTP 404] Not Found` and the URL. After the key the status
  line shows `[HTTP 404] Not Found`.
- 8.2 `g`, `http://no-such-host.invalid/`. A popup shows the error and
  `Reload to try again.` After it, `r` tries again (same popup).
- 8.3 After 8.2 press Backspace: the previous page loads.

## 9. What to paste back

- The pass or fail of each numbered item.
- The table of step 2 (`key: action`) and the result of 2.2.
- The three memory numbers of step 4.
- The exact text of every popup in steps 5 to 8.
- Anything that looked wrong: a stuck screen, a wrong color, a crash text.
